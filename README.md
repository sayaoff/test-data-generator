# Test Data Generator

Локальное веб-приложение для создания пользовательских данных для позитивного и негативного тестирования.

## Возможности

- понятный интерфейс в браузере;
- работает на macOS и Windows;
- выбор количества записей;
- корректные данные или данные с намеренными ошибками;
- генерация имени, фамилии, email, телефона, логина и пароля;
- предпросмотр в таблице;
- скачивание в JSON и CSV;
- автоматические тесты.

> Данные создаются локально на компьютере и никуда не отправляются.

## Запуск на macOS

Требуется Python 3.10 или новее. Tkinter и дополнительные библиотеки не нужны.

1. Распакуйте проект.
2. Нажмите на `start_mac.command` правой кнопкой мыши.
3. Выберите **«Открыть»** и подтвердите запуск.
4. Приложение автоматически откроется в браузере.

Если файл не запускается, откройте Терминал в папке проекта и выполните:

```bash
chmod +x start_mac.command
./start_mac.command
```

Пока приложение используется, окно Терминала должно оставаться открытым. Для остановки нажмите в нём `Control+C`.

## Запуск на Windows

Дважды нажмите `start_windows.bat`. Приложение откроется в браузере.

## Ручной запуск

```bash
python3 web_app.py
```

Затем откройте в браузере:

```text
http://127.0.0.1:8765
```

## Консольный режим

```bash
python3 main.py --count 10 --format csv
python3 main.py --count 5 --invalid
```

## Запуск тестов

```bash
python3 -m unittest discover -s tests -v
```

## Структура проекта

```text
├── web_app.py              # локальный веб-сервер
├── index.html              # интерфейс в браузере
├── main.py                 # консольный интерфейс
├── generator.py            # генерация данных
├── exporters.py            # экспорт в JSON и CSV
├── start_mac.command       # запуск на macOS
├── start_windows.bat       # запуск на Windows
├── tests/
│   ├── test_generator.py
│   └── test_exporters.py
├── .gitignore
└── README.md
```
